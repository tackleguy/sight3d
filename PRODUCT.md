# Sight3D

Sight3D is a desktop and browser 3D modeler based on the supplied DraftDown application. The user’s priority is SketchUp-like ease of use and AI assistance. Preserve the existing geometry engine, import/export, plugins, and advanced modeling tools.

The primary workflow is drawing a flat shape, using Push/Pull to make a solid, and orbiting to inspect it. Beginners see essential tools first, with advanced tools available on demand. AI is a visible modeling companion with Build (model operations) and Learn (instructions without tool execution) modes. The existing Anthropic integration uses the user's own API key. Do not imply AI works without configuration or that the product is affiliated with SketchUp.
